═══════════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

IF TESTS FAIL:

1. "Cannot connect to PostgreSQL":
   → Check TEST_DB_URL or HOSPITAL_DB_URL
   → Verify PostgreSQL is running: psql -U <user> -d <db>

2. "Table already exists":
   → Tests clean up after themselves
   → If interrupted, run: DROP TABLE cdc_test_* CASCADE;

3. "Permission denied on data_change_log":
   → Grant INSERT to test user
   → Or run tests as database owner

4. Performance tests fail (<5ms threshold):
   → Expected on slow machines / Docker
   → Adjust threshold in test_cdc_performance.py line 95

5. "lock_timeout" test fails:
   → PostgreSQL < 9.3 doesn't support lock_timeout
   → Upgrade or skip migration test
